# 资源详情页单元信息显示指南

## 问题说明

在资源详情页面，**不应该显示整个教材的所有单元列表**。资源详情页应该只显示**当前资源本身的信息**。

## 设计原则

### 1. 资源详情页 vs 教材目录页

- **资源详情页** (`/resources/:id`)：显示单个资源的信息
- **教材目录页** (`/catalog/:catalogId`)：显示整个教材的结构和所有资源

### 2. 单元信息的显示逻辑

资源详情页应该根据 `resource.unit` 的值来决定显示什么：

#### 情况 1：`resource.unit = "整本教材"`

**显示内容**：
- 可以显示整个教材的单元列表（作为参考信息）
- **但必须明确标注**：这是"整本教材"，显示的是"该教材的所有单元"（作为参考）

**实现方式**：
```typescript
if (resource.unit === '整本教材' && resource.catalog_id) {
  // 可以调用 GET /api/catalogs/:catalogId/units 获取单元列表
  // 但需要明确标注这是"整本教材"的参考信息
  const units = await fetch(`/api/catalogs/${resource.catalog_id}/units`);
  // 显示时标注："整本教材（该教材包含以下单元）"
}
```

#### 情况 2：`resource.unit = "第一单元"`（具体单元）

**显示内容**：
- **只显示该资源所属的单元信息**
- 可以显示该单元在教材中的位置（如"第1单元，共8个单元"）
- **不应该显示整个教材的所有单元**

**实现方式**：
```typescript
if (resource.unit && resource.unit !== '整本教材') {
  // 只显示当前资源的单元信息
  // 可以显示：所属单元、单元序号、在教材中的位置等
  // 不要调用 GET /api/catalogs/:catalogId/units
}
```

#### 情况 3：`resource.unit = null`（未设置单元）

**显示内容**：
- 不显示单元信息
- 可以提示："该资源未设置所属单元"

## 当前问题

从截图看，资源详情页显示了"【教材结构】"部分，里面显示了"单元列表"，显示了"第1单元 数据收集整理 1"。

**问题分析**：
1. 这个资源是"整本教材"（`unit = "整本教材"`）
2. 前端调用了 `GET /api/catalogs/:catalogId/units` 获取了整个教材的单元列表
3. 显示时没有明确标注这是"整本教材"的参考信息

## 建议修改

### 方案 1：明确标注（推荐）

如果资源是"整本教材"，显示单元列表时应该：
- 标题改为："【教材结构】（整本教材参考）"
- 或者："该资源为整本教材，以下是该教材包含的单元："

### 方案 2：简化显示

如果资源是"整本教材"，可以：
- 不显示单元列表
- 只显示："所属单元：整本教材"
- 提供链接："查看该教材的完整结构" → 跳转到 `/catalog/:catalogId`

### 方案 3：根据 unit 值决定

```typescript
// 伪代码
if (resource.unit === '整本教材') {
  // 显示整个教材的单元列表（标注为参考信息）
  showCatalogUnits(resource.catalog_id, { label: '整本教材参考' });
} else if (resource.unit) {
  // 只显示当前资源的单元信息
  showResourceUnit(resource.unit, resource.unit_index);
} else {
  // 不显示单元信息
  showNoUnit();
}
```

## API 接口说明

### 资源详情接口

`GET /api/resources/:id` 返回的资源对象包含：
- `unit`: 资源所属单元（`"整本教材"` 或 `"第一单元"` 或 `null`）
- `unit_index`: 单元序号（用于排序）
- `catalog_id`: 绑定的教材目录ID
- `catalog_info`: 教材目录基本信息

### 教材目录单元列表接口

`GET /api/catalogs/:catalogId/units` 返回整个教材的所有单元列表。

**注意**：这个接口是为"教材目录页"设计的，不是为"资源详情页"设计的。

## 总结

**核心原则**：
- 资源详情页应该显示**资源本身的信息**，而不是整个教材的结构
- 如果资源是"整本教材"，可以显示整个教材的单元列表，但需要明确标注这是参考信息
- 如果资源是具体单元，只显示该单元的信息，不要显示整个教材的所有单元
