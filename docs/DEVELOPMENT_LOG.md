### [未指定日期] - 认证与用户模块

#### ✨ 新增功能

- **认证模块 (auth)**
  - 用户注册功能
  - 用户登录功能（JWT Token）
  - Token 验证中间件
  - 密码加密和验证

- **用户模块 (user)**
  - 用户信息 CRUD 操作
  - 用户列表查询（支持分页）
  - 用户详情查询
  - 用户信息更新

#### 📝 技术实现

- JWT Token 使用 RS256 算法（公私钥对）
- 密码使用 bcrypt 加密（salt rounds: 10）
- 实现统一的错误处理机制

## 📝 开发笔记

### 技术决策

1. **选择 MySQL 而非 MongoDB**
   - 原因：数据结构相对固定，关系型数据更适合
   - 考虑：未来可能需要复杂查询和事务支持

2. **使用 TypeScript**
   - 原因：类型安全、更好的 IDE 支持、团队协作
   - 收益：减少运行时错误，提高代码质量

3. **文件存储使用本地文件系统**
   - 当前：简单直接，适合中小规模
   - 未来：考虑迁移到对象存储（OSS/S3）

### 经验总结

1. **模块化设计**
   - 按功能模块划分，便于维护和扩展
   - 每个模块包含完整的 MVC 结构

2. **中间件使用**
   - 认证中间件统一处理用户身份
   - 错误处理中间件统一处理异常

3. **数据库设计**
   - 合理设计外键关系
   - 预留扩展字段
   - 考虑查询性能
