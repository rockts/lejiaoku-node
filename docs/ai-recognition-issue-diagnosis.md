# AI 识别问题诊断报告

## 问题描述

用户上传"数学六年级下册"资源，但AI识别结果显示为"语文二年级上册"，识别结果完全错误。

## 根本原因分析

### 1. AI识别服务是占位实现

**代码位置：** `src/resource/resource-parser.service.ts:62`

**问题：**
```typescript
/**
 * 使用AI解析教材信息
 * 注意：这里使用占位实现，实际应该调用AI API
 */
export async function parseTextbookWithAI(text: string): Promise<AIParseResult> {
  // TODO: 实际实现应该调用AI API（如OpenAI、Claude等）
  // 这里提供一个示例结构，实际使用时需要根据你的AI服务提供商进行实现
  
  // 示例：简单的关键词匹配（临时方案）
  // 实际应该使用AI API进行结构化解析
```

**现状：**
- ❌ **没有真正的AI识别**：只是简单的关键词匹配
- ❌ **匹配逻辑有问题**：使用 `text.includes(subject)` 匹配，如果文本中同时包含多个学科关键词，会匹配到第一个
- ❌ **没有上下文理解**：无法理解"数学六年级下册"这样的完整语义

### 2. 关键词匹配的缺陷

**代码逻辑：**
```typescript
// 尝试提取学科
for (const subject of subjects) {
  if (text.includes(subject)) {
    result.subject = subject;
    break;  // 找到第一个就停止
  }
}
```

**问题：**
- 如果PDF文本提取失败或提取到无关内容，可能匹配到错误的学科
- 如果文本中包含多个学科关键词（如"语文数学"），会匹配到第一个（"语文"）
- 没有优先级判断，无法区分哪个关键词更准确

### 3. 数据验证

从数据库查询结果看：
```
ID 49: title="数学六年级下册"
      auto_meta_result: {"subject":"语文","grade":"二年级","volume":"上册"}
      
ID 48: title="数学二年级下册"  
      auto_meta_result: {"subject":"语文","grade":"二年级","volume":"上册"}
```

**发现：**
- 所有资源都返回了相同的错误结果："语文二年级上册"
- 说明文本提取可能失败，或者匹配逻辑总是返回默认值

## 系统可用性评估

### ✅ 可以使用的部分

1. **手动输入功能**：用户上传时可以手动填写 `subject`、`grade`、`textbook` 等字段
2. **编辑功能**：资源创建后可以手动编辑修正信息
3. **教材目录绑定**：可以手动绑定到正确的教材目录
4. **基础功能**：资源上传、下载、列表展示等核心功能正常

### ❌ 不能依赖的部分

1. **AI自动识别**：当前只是占位实现，识别结果不可靠
2. **自动元数据提取**：无法从文件内容自动提取准确的学科、年级等信息

## 解决方案

### 方案一：禁用AI识别（推荐，立即实施）

**步骤：**
1. 在资源上传时，不触发AI识别流程
2. 要求用户手动填写所有必要信息
3. 将 `auto_meta_status` 默认设置为 `pending`，不执行识别

**优点：**
- 立即解决问题
- 避免错误数据污染系统
- 用户明确知道需要手动填写

**缺点：**
- 增加用户操作负担
- 需要前端配合，确保必填字段验证

### 方案二：集成真正的AI服务（长期方案）

**需要：**
1. 选择AI服务提供商（OpenAI、Claude、MiniMax等）
2. 设计提示词（Prompt），明确要求识别学科、年级、册别、版本
3. 实现API调用和错误处理
4. 添加置信度阈值，低于阈值的结果不采用

**示例提示词：**
```
请从以下文本中识别教材信息：
- 学科（如：语文、数学、英语等）
- 年级（如：一年级、二年级...六年级、七年级等）
- 册别（上册、下册、全一册）
- 版本（如：人教版、苏教版等）

文本内容：
{text}

请以JSON格式返回结果。
```

### 方案三：改进关键词匹配（临时方案）

**改进点：**
1. 优先从资源标题（`resource.title`）提取信息
2. 如果标题包含完整信息（如"数学六年级下册"），直接解析标题
3. 文件内容提取仅作为补充

**实现：**
```typescript
// 优先从标题解析
const titleInfo = parseTitle(resource.title); // "数学六年级下册" -> {subject: "数学", grade: "六年级", volume: "下册"}
if (titleInfo.subject && titleInfo.grade) {
  return titleInfo; // 标题信息完整，直接使用
}
// 否则才从文件内容提取
```
