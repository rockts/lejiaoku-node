# 用户资料更新问题排查

## 🔍 如何查看详细错误

### 方法 1: 查看服务控制台

服务控制台应该会输出：
- `👮‍♂️ 验证更新用户数据` - 请求到达
- `📦 请求体:` - 请求数据
- `🚧 错误信息:` - 具体错误
- `❌ 未处理的错误:` - 未预期的错误（如果出现）

### 方法 2: 查看浏览器开发者工具

1. 打开开发者工具（F12）
2. 切换到 Network 标签
3. 点击保存
4. 查看 `PUT /user/profile` 请求：
   - Status: 查看状态码
   - Response: 查看错误消息

## 📋 常见错误及解决方法

### 1. "请提供要更新的数据"

**原因**: 请求中没有 `update` 字段

**解决**: 确保请求格式为：
```json
{
  "update": {
    "name": "新用户名"
  }
}
```

### 2. "没有要更新的字段"

**原因**: `update` 是空对象，或者字段名不正确

**解决**: 确保 `update` 中包含至少一个有效字段：
- `name` - 用户名
- `email` - 邮箱
- `password` - 密码

### 3. "请提供用户密码"

**原因**: 修改密码时未提供当前密码

**解决**: 如果 `update.password` 存在，必须提供：
```json
{
  "validate": {
    "password": "当前密码"
  },
  "update": {
    "password": "新密码"
  }
}
```

### 4. "服务暂时出了点问题"

**原因**: 未预期的错误（查看控制台日志获取详细信息）

**排查步骤**:
1. 查看服务控制台的错误日志
2. 检查数据库连接是否正常
3. 检查请求数据格式是否正确

## 🔧 测试请求格式

### 正确的请求格式

**只更新用户名**：
```json
{
  "update": {
    "name": "新用户名"
  }
}
```

**只更新邮箱**：
```json
{
  "update": {
    "email": "new@example.com"
  }
}
```

**修改密码**：
```json
{
  "validate": {
    "password": "当前密码"
  },
  "update": {
    "password": "新密码"
  }
}
```

**同时更新多个字段（不包含密码）**：
```json
{
  "update": {
    "name": "新用户名",
    "email": "new@example.com"
  }
}
```
